#House Price Prediction Using Machine Learning

## Project Overview

The purpose of this project is to forecast house prices using property features like area, bedroom count, bathroom count, parking, neighborhood characteristics and other amenities.

The project is an example of the full machine learning lifecycle from data preprocessing to exploratory data analysis (EDA), feature engineering, model training, model evaluation and the interpretation of the results.

## Dataset

House Price Prediction Dataset (Kaggle)

### Features Used

* Area
* Bedrooms
* Bathrooms
* Stories
* Parking
* Air Conditioning
* Preferred Area
* Furnishing Status
* Guest Room
* Basement
* Main Road Access
* Hot Water Heating

### Target Variable

* Price

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Machine Learning Model

* Linear Regression

## Exploratory Data Analysis

The following analyses were carried out:

* House price distribution
* Correlation heatmap

* Feature importance analysis

## Model Evaluation

### Results

* Mean Absolute Error (MAE): 979,679.69
* Root Mean Squared Error (RMSE): 1,331,071.42
* R² Score: 0.6495

## Key Findings

House prices have a strong positive relationship with property area.
Bathrooms had the greatest influence on the prediction model.
The benefits derived from air conditioning, parking spaces and preferred location were also found to have a significant effect on the value of the property.
The model was able to reflect the overall price trends and attain a good performance in predicting them.
